- **会話中にスタックチャンが使えるツールを追加** (会話モード、全プロバイダ): 時刻・日付の確認、本体の状態 (電池 / 近接センサー / 稼働時間)、「覚えておいて」で電源を切っても残るメモの保存・読み出し・削除、「N 分後に教えて」のリマインダー、音量の上げ下げ・ミュート・解除、「3 分のタイマーをセット」で LT タイマーの開始 / 停止 / 残り確認。LT タイマーの残り 1 分・終了・超過、リマインダーの時刻は会話中でもスタックチャン自身の声で知らせます
- **エージェントへの依頼 (ask_agent)**: 天気や調べものなど自分で答えられない質問を、設定したエージェント サーバーに投げて答えを受け取ります。サーバーの URL とトークンは設定ページ (Wi-Fi) から
- **右上に会話ステータス表示** (聞き取り中 / 考え中 / ツール実行中 / 応答中) を追加。ネコミミ LED もこの状態に連動でき、待ち受け中は通常の点灯、聞き取り中・実行中・応答中の色とパターンは設定ページから変更できます (即時反映)
- **XiaoZhi 対応の強化**: 上記ツールと表情 / 首振り / カタコト声を XiaoZhi サーバーからも使えるようにしました (MCP)。自前サーバー向けに、機体のシステム プロンプトを接続時に渡す独自拡張を追加
- **会話の安定性・速さ**:
  - Gemini の応答が 20〜30 秒遅れることがあった問題 (思考モードを無効化、区切り検出を調整)
  - 再接続に毎回 12 秒かかっていた問題、サーバーに 1 時間無音で切られた後の再接続が延々と失敗する問題 (メモリ不足) を修正
  - 起動直後に会話モードでマイクが反応しない問題を修正
  - カタコト声 (speak_katakoto) が sanoTTS 選択時に数秒待たされていた問題を修正
- 内部: JSON 処理を順次 ArduinoJson に移行中 (メモリ使用量の削減)
